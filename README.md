# Ibom Christmas Unplugged 4.0 — Logo Design Entry

This repository contains the official vector assets, source design files, and export formats for the **Ibom Christmas Unplugged 4.0 Logo Design Competition**, organized by the Akwa Ibom State Ministry of Culture and Tourism.

## 🎯 Theme Alignment
* **Theme:** Taste of Akwa Ibom: Our Food, Culture and Heritage
* **Concept:** Original logo concept capturing the rich culinary traditions, cultural heritage, and vibrant festival spirit of Akwa Ibom State.

## 📁 Repository Structure & File Verification
* `/exports` — Submission-ready files (PNG / Web formats, optimized under 1 MB limit)
* `/source` — Vector source files (`.ai`, `.svg`, `.eps`, or `.psd`) proving original authorship
* `/preview` — Presentation visual assets and mockups
